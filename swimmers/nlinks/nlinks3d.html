plot(state, ax=None, color='royalblue')[source]

Plot the N-link 3D magnetic swimmer in 3D space. state is dimension (2*N+6) where : - state[0:3] is the position of the head - state[3:6] is the orientation of the head (theta_x, theta_y, theta_z) - state[6:6+2*N] is the orientation of the link (phi^1_x, phi^1_y, phi^1_z, …, phi^N_x, phi^N_y, phi^N_z)

Parameters:

  • state (np.array) – State vector of the swimmer.

  • ax (matplotlib.axes._subplots.Axes3DSubplot, optional) – Matplotlib 3D axis. Defaults to None.

  • color (str, optional) – Color of the swimmer. Defaults to ‘royalblue’.

Returns:

The 3D axis with the swimmer plotted.

Return type:

matplotlib.axes._subplots.Axes3DSubplot
